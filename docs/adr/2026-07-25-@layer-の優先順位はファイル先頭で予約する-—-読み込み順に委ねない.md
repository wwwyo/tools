# `@layer` の優先順位はファイル先頭で予約する — 読み込み順に委ねない

- Status: Accepted
- Date: 2026-07-25

usuppera の rank stamp が円にならない不具合の真因は `border-radius` ではなく、**ビルド後だけ `border` が消えていた**こと。`dist/usuppera/index.html` ではツール CSS が `global.css` より先に読み込まれ、`@layer components` が最下位に固定されて Tailwind preflight の `base`（`border: 0 solid`）に負けていた。**cascade layer の順序は「どの layer 名が最初に登場したか」で確定し、後から書き直しても覆らない**（specificity とは別のルールで動き、`!important` では逆転する）。対策は `styles.css` の先頭に `@layer theme, base, components, utilities;` と**順序だけ先に予約**すること。独自 layer を増やす案は却下 — 順序管理というグローバル状態が増えて事故が増える。同型の罠が `shirobikari` にもあったので**同日に予防修正**した（直す時にしか水平展開はできない）。検証は dev でなく **build + preview** を基準にした（dev では再現せずビルド成果物でだけ壊れるタイプ）

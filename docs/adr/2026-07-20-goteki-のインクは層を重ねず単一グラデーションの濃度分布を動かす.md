# goteki のインクは層を重ねず単一グラデーションの濃度分布を動かす

- Status: Accepted
- Date: 2026-07-20

「着弾痕 + 浸透前線」の2層 + `mix-blend-multiply` は重なり境界が輪に見え、現実の単一液体と違った。`@property` でグラデーション stop を動かすと、サイズ拡大でなく濃度変化として表現できる。広がりの進行は一定リズムでなく毛細管浸透（`Washburn 則`、序盤速く後半遅い）に寄せる。`feDisplacementMap` は既定が `linearRGB` 寄りで色が眠くなるため `color-interpolation-filters="sRGB"` を付ける

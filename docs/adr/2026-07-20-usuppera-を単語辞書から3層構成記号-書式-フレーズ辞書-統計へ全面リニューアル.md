# usuppera を単語辞書から3層構成（記号・書式 / フレーズ辞書 / 統計）へ全面リニューアル

- Status: Accepted
- Date: 2026-07-20

旧辞書は「活用」「効率的」「を提供」のような単語1語エントリが偽陽性の温床で、**weight 調整では直らないと判断して削除**した。「近年、」「注意が必要です」「解説します」も人間の技術文書で踏みすぎるため削除 — 検出力を捨ててでも誤検出を減らす側を取った。統計層は `truthlens` の burstiness をそのまま移植せず、日本語向けに**文長の CV・文末の単調さ・文頭の均一性**へ置き換え。統計減点には**上限**を設けた（箇条書きや同型文が並んだだけで崖にならないよう、検出力より被害上限を優先）。絵文字は個別列挙でなく `\p{Extended_Pictographic}`

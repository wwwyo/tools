# ケイリョウ（keiryo）

画像の圧縮率を拡張子ごとに比較します。

## 使い方

- 画像をドラッグ&ドロップ / クリックで選択 / Cmd+V で貼り付け、または「サンプル画像で試す」
- 読み込むと、サムネイルと検品テーブル（ファイル名・拡張子・実際の形式・MIME・容量・寸法・画素数・アスペクト比・最終更新・透過の有無・色深度・EXIF 向き）が出る。拡張子と実形式が食い違っていれば警告行が出る
- 品質スライダーと長辺の上限（なし / 2048 / 1600 / 1200 / 800px）を1組だけ操作すると、元ファイル / JPEG / WebP / AVIF / PNG の梯子（ラダー）が全行その設定で再エンコードされる
- 先頭の「元ファイル」行だけは再エンコードせず、読み込んだバイト列そのものをダウンロードできる比較用の基準行
- PNG 行は可逆圧縮のため品質は効かない（行内に注記が出る）
- ブラウザが書き出せない形式（AVIF 非対応環境など）は行として残しつつ「このブラウザでは書き出し不可」と表示し、ダウンロードやバーは出さない
- 解析・変換はすべてページ内 Canvas で完結し、画像は外部に送信しない

## 設計と判断

### 行を「サイズ違い」ではなく「拡張子違い」にした理由

このツールの問いは「どの拡張子でどれぐらい圧縮されるか」であって、「同じ拡張子でどこまで縮小できるか」ではない。前者を見せるなら1行=1形式にして並べるのが素直で、長辺は形式を横断する共通パラメータとして画面全体で1つに畳んだ。1行=1サイズで形式を切り替える構成だと「JPEG と WebP のどちらが軽いか」を見るのに2回見比べる必要があり、聞きたい問いに対して1手余分になる。

### 未対応の形式を隠さずフォールバックもしない理由

非対応ブラウザで JPEG に無言で差し替えると、「WebP がどれだけ効くか」を聞いているのに答えが返ってこないのと同じで、しかも差し替わったことに気づきにくい。行として残したまま「このブラウザでは書き出し不可」と明示すれば、見比べる材料が足りていないという事実がそのまま伝わる。対応可否は起動時に 1×1 canvas への `toBlob` で実機 probe し、`blob.type` が要求した mime と一致するかで判定する（無言で別形式を返すブラウザがあるため）。

### PNG を行に含めた理由

PNG は非可逆圧縮の設定項目（品質）が意味を持たないが、それは「比較に値しない」ことを意味しない。可逆圧縮の基準点があることで、非可逆形式がどれだけバイト数を削っているかの上限（＝可逆で正直に落とせる量との差）が見える。品質スライダーが効かない事実は隠さず、行内に「可逆・品質は効きません」と注記する。

### 品質と長辺上限を画面全体で1組にした理由

行ごとに画質基準が違うと形式間の比較にならない。同じ品質・同じ長辺のまま拡張子だけ変えて出力サイズを比べたいので、変わるのは行（拡張子）だけにした。

### 長辺の上限をアップスケール方向に伸ばさない理由

長辺の上限は select の選択肢だが、画像の長辺以上の値を選んでもアップスケールでボケるだけなので、その値は `disabled` にして選べなくする。候補から消さずに残すのは、なぜ選べないかが見て分かるようにするため。

### 逐次エンコード（Promise.all にしない）

複数行を並列で `canvas.toBlob` すると、大きな画像では同時に複数枚分のフルサイズ canvas を確保することになりメモリを食う。1行ずつ await して順番に確定させ、品質・長辺上限変更のデバウンス中に前回の実行が終わっていない場合は「実行中なら直後にもう一度だけやり直す」直列化で対応する。

### ヘッダー読み取りは 64 KiB

フォーマット判定と PNG IHDR は先頭 32 byte で足りるが、JPEG の Exif（APP1）セグメントは 16bit 長で最大 64 KiB になりうる。Orientation タグまで届かせるため、ヘッダーはまとめて 64 KiB 読む。画像全体を ArrayBuffer に載せないのは、巨大ファイルでメモリを二重に持たないため。

## ファイル構成

```
keiryo/
├── index.html    エントリ（title / description は一覧・OGP 自動生成に使われる）
├── main.ts       UI・状態管理・逐次エンコードの直列化
├── imageMeta.ts  マジックナンバー判定・PNG IHDR・JPEG Exif Orientation・透過検知・検品メタデータ組み立て
├── encode.ts     長辺キャップ付きリサイズ・canvas 再エンコード・書き出し対応 probe・サンプル画像生成
├── styles.css    :root テーマ上書き・行の入場アニメーション・比率バーの transition
└── og.tsx        OGP カード用の画面ミニチュア
```

# 宇宙尖兵 重力平衡圏（uchusenpei）

海野十三『宇宙尖兵』の「重力平衡圏」「宇宙の墓地」「展望室」の場面を、見回せる 3D 空間で再生する試作。Meta Quest などのブラウザでは WebXR で中に入れる。

確かめたいのは「文章から 3D 空間を作れるか」。最終的には朗読と映像が連動する体験型の本にしたいが、この試作は空間の側だけを見る。

## しくみ

```
本文（青空文庫） → 台本 script.json（AI が書く） → 再生器（main.ts / world.ts） → three.js の WebXR シーン
```

- **台本**（`script.json`）は 3 つでできている。今回の台本は AI が本文から書いた
  - `camera`: 始まりの視点。見る人は艇に乗っていて、艇の位置（`position`）と顔の向き（`yaw` / `pitch`、度）で書く
  - `objects`: 何をどこに置くか（月、地球、星、隕石の群れ、探照灯など）。`onShip: true` の物（卓子の本、引力の図）は艇と一緒に動く
  - `beats`: 文ごとの区切り。1 つの区切りに、文（`text`）・原文の章（`chapter`）・本文そのままか補いか（`quote`）・読み上げの目安の秒数（`seconds`）・その文のあいだに何をどう動かすか（`actions`、`at` は文の頭からの秒）をまとめる
- **再生器**は前の文が終わると次の文へ進む。読み上げを入れたときは、声が終わるまで文の終わりで台本の時計を止めて待つ。台本が指示できることは 3 つだけ
  - `level`: 見え方・明るさを 0〜1 で変える（月が明るくなる、探照灯が点く、図が消える、宇宙の墓地で太陽の光が弱まる）
  - `start`: その物の動きを始める（本が浮く、物を放り出す、二つの引力がつり合っていく）
  - `camera`: 視点を `dur` 秒かけて動かす。書いた項目だけが変わる（艇が月へ近づく、墓地を見下ろす、最後に振り返って地球を見る）
- **どこからでも始められる**: 再生は前の状態を積み上げない。`timeline.ts` が台本を「台本の時刻 → 各物の状態（`level`、直近の `start` からの経過秒、時刻そのもの）と視点」の関数に直し、物（`world.ts`）はその状態だけから見た目を決める。だから任意の文・時刻へ飛んでも、最初から再生したときと同じ見え方になる。画面の位置バー、「前の文」「次の文」、URL の `#b06`（文の id）で飛べる。再生中の文は URL に残る
- 括弧つきの文は場面をつなぐための補い（`quote: false`）
- 台本は再生前に `parseScript` で形を確かめる。AI が書き損じたら、どこが悪いかを画面に出して止まる

秒の時刻表ではなく文で区切るのは、朗読と映像を連動させるため。文ごとの区切りに、あとから「これは何？」の説明や合成音声の音声ファイルを足せる。

物の種類を増やせば別の場面も書ける。台本だけ差し替えて試せるよう、再生器の側に場面固有のことは書かない（場面の数値はすべて台本にある）。

## 判断

- **生成モデルではなくコードで空間を作る**: 地球と月が遠くに浮かぶ何もない空間は、文章から 3D 世界を作るモデルが苦手な場面（部屋や風景が得意で、空は崩れやすい）。コードなら距離や大きさを数値で置け、朗読の進み具合に合わせて動かせる
- **無料のものだけ**: three.js（MIT）とブラウザの機能だけで動く。有料の生成サービスは使わない
- **月と地球はページ内で手続き生成**: NASA の公開画像を使うつもりだったが、作業環境から取得できなかったため、球面上のノイズとクレーターを canvas に描いて貼っている。外部の画像に依存しないので、このサイトの CSP（`img-src 'self'`）にもそのまま収まる。差し替えるなら `world.ts` の `moonTextures` / `earthTexture` を画像の読み込みにする
- **大きさは本文の印象に合わせた**: 本文は月面が「手にとるように」見えると書くので、月を実際より大きく置いている（実際の平衡点からは月が約 3.4 度、地球が約 2.2 度）。科学は作品のまま、つまり「隕石が平衡点に溜まる」も本文通りに描く
- **視点は開始時の頭の位置**: `local` の参照空間を使い、座っても立っても同じ見え方になるようにした。地球は後ろにあり、振り返ると見える
- **カメラを動かす**: 止まった景色では場面が伝わらなかったので、台本の `camera` で艇を月へ近づけ、宇宙の墓地の上で見下ろし、最後に振り返って地球を見せる。画面では顔の向きも台本どおりに動き、ドラッグした分はそれに足す。VR では向きを見る人の頭に任せ、艇の位置だけを動かす（向きを勝手に回すと酔うため）
- **光の見せ方**: VR では後処理（ブルームなど）が使えないので、光のにじみは加算合成の板（太陽、星、探照灯の光源）と、ふちほど光るシェーダー（地球の大気、探照灯の光の筋）で作る。明るさはトーンマッピング（ACES）で丸める
- **宇宙の墓地は暗くする**: 本文の「探照灯」「あの青白い光の中に黒い小山」に合わせ、墓地では太陽の光を落とし、艇の探照灯がゆっくり掃いた所だけが見えるようにした
- **引力の図は計算で描く**: 艇の中に、左に地球・右に月の小さな図を浮かべ、艇の点が月へ近づくと二本の矢印がそろう。矢印の長さは本文の「距離の自乗に反比例」と、地球の質量が月の 81 倍であることから計算している（つり合うのは地球から月までの 9 割の所）
- **字幕は箱を敷かない**: 大きな明朝を影で浮かせ、文ごとにふわっと出す。章は変わったときだけ出す。補いの文（括弧つき）は小さく淡くする
- **動きを減らす設定**: `prefers-reduced-motion` のときは視点を滑らかに動かさず、文の区切りで切り替える。字幕のふわっと出る動きも止める
- **既定は進み続ける**: 再生は自動で進み、止めたいときだけ止める（画面のボタン、VR ではコントローラの引き金）
- **読み上げはブラウザ内蔵の音声合成**: 外部サービスは使わない。既定は切。端末によっては日本語の声が無い

## ファイル構成

```
uchusenpei/
├── index.html    エントリ（説明文は #app の外）
├── main.ts       描画・台本の時計・字幕・VR・操作
├── timeline.ts   台本を「時刻 → 状態」に直す（どこからでも始められる仕組み）
├── world.ts      台本の物を three.js の物にする
├── script.ts     台本の型と検証
├── script.json   場面の台本
├── timeline.test.ts  視点の補間のテスト
├── textures.ts   月・地球の手続き生成、VR 内字幕の描画
└── styles.css    暗い配色とボタン
```

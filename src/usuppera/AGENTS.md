# usuppera の編集ルール

ツールの設計そのものは README.md を読む。ここには「触るときに迷う判断」だけを置く。

## `EIGO_ALLOWLIST`（急な英語の除外語）

「急な英語」層は検知語を列挙せず、日本語に挟まれた小文字ラテン語 1 語という形だけで拾ってから allowlist で引く。語を足すときの判断基準:

- **入れる**: それが名前である語。`typescript` `docker` `npm` のような言語・ツール・製品名、`issue` `closed` `merge` `deploy` のような開発ワークフロー語、`api` `json` `cache` `token` のような一般技術語。日本語話者が普段そのまま打つ語は、気取って英語にしたのではないので検知しない
- **入れない**: `robust` `seamless` `alignment` `insight` のような抽象評価語。日本語で書けるのに英語のまま置かれた語こそが検知対象なので、ここを広げすぎると層ごと死ぬ
- 3 文字未満（`id` `db` `ui` `ci`）と大文字始まり・全大文字（`React` `API`）はパターン側で既に落ちているので列挙しない
- 迷ったら「この語を日本語に置き換えられるか」で判断する。置き換えられるなら検知対象、置き換えると不自然なら allowlist
